## 개요

`AX_대시보드`는 사업계획서(v0.97)를 기반으로 한 **일산병원 AI 전환(AX) 추진 현황 대시보드**입니다.
단일 HTML 파일 하나로 동작하며, 5개 탭(개요 · 사업 타임라인 · 전략과제 · 진척 분석 · 벤치마크)과
실시간 협업 세부계획 시트, 동시 접속자 표시, PWA 설치, AI 비서 위젯을 제공합니다.

### 기술 스택
- **프론트엔드**: 단일 파일 HTML / CSS / Vanilla JS, Chart.js, Noto Sans KR
- **백엔드**: Supabase (Postgres + Realtime `postgres_changes`/`Presence` + RLS + Google OAuth)
- **협업 시트**: `contenteditable` 셀, 셀 단위 서식(jsonb), 열 설정·너비·병합(jsonb), 시스템 클립보드(TSV) 복붙
- **배포**: GitHub(`ajsiwkvue-sudo/dashboard-projects`) → Vercel 자동 배포 + GitHub Pages

### 주요 기능
- **5개 탭**: 개요(KPI·전체 진척), 사업 타임라인(단계·마일스톤·활동·리스크 + 간트), 전략과제(노션식 갤러리·표·보드), 진척 분석(팀·과제 비교), 벤치마크
- **실시간 협업**: 마일스톤 상태·날짜, 세부계획 시트가 동시 접속자에게 실시간 반영 (Supabase Realtime)
- **동시 접속자(Presence)**: 누가 어느 화면/셀을 보고 있는지 상단에 표시
- **엑셀급 스프레드시트**: 셀 단위 서식·드래그 다중선택·열 너비 조절·셀 병합·필터/정렬·복붙·되돌리기
- **노션식 레이아웃 전환**: 갤러리 / 표 / 보드(칸반 드래그로 상태 변경)
- **PWA**: manifest + service worker 로 설치 가능, 모바일 최적화(≤640px)

## 이번 세션 작업 (2026-07-13)

### 1. 새로고침 시 마지막 탭 유지
새로고침하면 항상 "개요"로 돌아가던 문제 해결. `localStorage`에 활성 탭을 저장하고
로드 시 복원하여, 보고 있던 화면 그대로 새로고침되도록 함.

### 2. 배포 URL 정비
`ax-dashboard-one.vercel.app` → **`ilsan-ax.vercel.app`** 로 병원 정체성이 담긴 깔끔한 주소 추가.
(`ax-dashboard.vercel.app`은 전역 선점 상태라 불가) 기존 주소도 유지되어 예전 링크 호환.

### 3. 전략과제 갤러리 개선
- **첫 진입 버그 해결**: 갤러리가 처음엔 세로 1열로만 보이다가 표/보드를 눌러야 다열이 되던 문제.
  원인은 `#taskGrid` 컨테이너가 grid 상태로 남아 카드가 좁은 트랙에 갇힌 것 — 렌더 시 컨테이너를 block으로 강제하여 첫 진입부터 정상 다열 표시.
- **목표(색상)별 그룹 행**: 목표1(파랑)·목표2(보라)·목표3(초록)으로 나눠 각 목표를 한 행(밴드)으로 묶어 표시.
- **행 꽉 채우기**: `auto-fill` → `auto-fit` 로 변경하여 우측 빈 공간 없이 카드가 행 전체를 균등하게 채움.

### 4. 동시 접속자 위치 트래킹 — Freeze 버그 해결 (핵심)
"여기저기 이동하는데 어느 순간 위치가 고정된다"는 문제를 정밀 진단.
- **1차 발견**: 표시 로직이 상태 배열에서 가장 **오래된** 값(`arr[0]`)을 뽑아 옛 위치가 남던 문제 → 최신 값(`arr[마지막]`)으로 수정.
- **근본 원인**: Presence **채널이 `closed` 상태로 죽어도 재연결 로직이 없어** `track()`이 타임아웃 → 그 순간부터 위치 영구 고정.
- **해결**: `ensurePresence()`(채널이 죽으면 자동 재생성) + 상태 오류 시 재연결 + **15초 하트비트 자가복구** + 이벤트 한도 5→10 상향.
- **검증**: 10회 연속 탭 이동 테스트에서 채널이 끊겨도 다음 동작 즉시 `joined`로 복구되어 위치가 정확히 따라옴(영구 고정 없음).
