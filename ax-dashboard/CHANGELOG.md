## 개요

`AX_대시보드`는 사업계획서(v0.97)를 기반으로 한 **일산병원 AI 전환(AX) 추진 현황 대시보드**입니다.
단일 HTML 파일 하나로 동작하며, 좌측 사이드바 네비게이션으로 6개 화면
(개요 · 사업 타임라인 · 전략과제 · 진척 분석 · 운영·회의록 · 벤치마크)을 제공합니다.
전략과제의 세부실행계획은 **WBS(작업분해구조) 간트**로 관리하며, 실시간 협업·동시 접속자 표시·PWA 설치를 지원합니다.

### 기술 스택
- **프론트엔드**: 단일 파일 HTML / CSS / Vanilla JS, Chart.js, Noto Sans KR
- **백엔드**: Supabase (Postgres + Realtime + RLS + Google OAuth)
- **배포**: GitHub(`ajsiwkvue-sudo/dashboard-projects`) → Vercel 자동 배포 + GitHub Pages
- **PWA**: manifest + service worker(network-first) — 설치 가능, 항상 최신본 제공

### 디자인 원칙
- **차분한 콘솔형 팔레트**: 목표색만 사용 — 목표1 네이비(#3d5a98) · 목표2 틸(#0e8c86) · 목표3 오커(#c1791d)
- **목표·지표 색 일원화**, 비목표 장식 요소는 중립(먹색/회색)으로 색 노이즈 최소화
- **상태색만 최소 유지**: 완료(녹) · 진행중(앰버) · 예정(회) · 지연(빨)

## 주요 기능

### 화면(좌측 사이드바 네비)
- **개요**: 비전 체계도, KPI, 전체 진척률, 목표별 진척도, 월별 마일스톤 추이
- **사업 타임라인**: 단계별 목표·마일스톤·활동·리스크 매트릭스 + 과제 간트
- **전략과제**: 노션식 레이아웃(갤러리 · 표 · 보드) — 목표(색상)별 그룹, 담당자(정/부) 표시, 담당자·팀·상태 필터
- **진척 분석**: 부서별 담당 업무·세부 진척 현황, 협력부서 참여 빈도
- **운영·회의록**: 회의록 + 액션아이템(Supabase 실시간 공유)
- **벤치마크**: 타 병원·기업 AX 사례

### 세부실행계획 = WBS 간트
- **20개 컬럼(5영역)**: 작업정보(WBS·대과제·세부과제·작업명·담당자·우선순위·가중치), 일정관리(계획/실제 시작·종료·기간·남은기간·지연일수), 진행관리(진행률·상태), 작업관리(선행작업·산출물·완료기준·비고), 이력관리(최종수정·수정자)
- **자동 수식**: 기간 = 계획종료−계획시작, 남은기간, 지연일수, 상태 자동판정(예정/미착수/진행중/완료/지연)
- **가중치 롤업**: 과제 진척율 = Σ(진행률×가중치)/Σ가중치 · 계획공정률 · SPI (WBS 화면 내 표시)
- **간트 막대**: 데이터 컬럼 오른쪽 끝에 주간 그리드 막대
- **엑셀급 편집**: 셀 서식(색·정렬·굵기)·복사/붙여넣기·되돌리기·행/열 삽입·필터/정렬·셀 병합·열 너비 조절·좌측 열 고정·헤더 고정

### 협업·인프라
- **실시간 동기화**: 마일스톤 상태·세부계획이 접속자 모두에게 즉시 반영
- **동시 접속자(Presence)**: 누가 어느 화면/셀을 보는지 표시(자가복구 재연결)
- **사이드바 접기/너비 조절**: « 접기 → 우측 확대, 드래그로 너비 조절(localStorage 저장)
- **새로고침 시 마지막 탭 유지**

## 작업 이력 (요약)

### 2026-07-14 (WBS 간트 고도화 — wbsgantt.app 벤치)
- **EVM 공정표 프레임 전환**: 세부계획을 3열 작업(대과제·세부과제·작업명) + EVM 지표(계획완료율·실제완료율·차이·작업일수·실적일수)로 재구성
- **① 대과제 계층 접기/펼치기 + 상위 자동집계 행**: 대과제별 그룹 헤더에 롤업(가중 계획/실제완료율·차이·영업일 기간·기간 요약·건수) 자동 표시, ▼/▶ 개별 토글 + 리본 `⊟ 접기/펼치기` 전체 토글(localStorage 저장). phase가 블록 첫 행에만 있어도 원본 순서 기준 carry-down으로 정확히 그룹핑
- **② 오늘 날짜선 + 지연만 필터**: 간트 현재 주 열에 빨간 세로선, `📍 오늘로` 스크롤, `⚠ 지연만` 토글로 상태=지연 항목만 보기
- **③ 영업일 일수**: 작업일수·실적일수를 주말 제외 근무일 기준으로 계산
- **④ 엑셀(CSV) 내보내기**: `📥 엑셀`로 현재 표(보이는 열·행)를 UTF-8(BOM) CSV 저장 — Excel에서 바로 열림
